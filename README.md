## 功能

**外观与交互（v1.27）**
- **深色胶囊 + Acrylic 详情卡片**：主轨使用近黑色自绘底与等宽端帽裁切，保证任何壁纸上都有稳定的半圆外形；局部详情卡片继续使用 Acrylic 暗色材质
- **平滑边缘**：主轨以 4 倍超采样绘制后缩小，完整展开态由逐像素 alpha 形成圆弧，避免 Win32 硬区域裁切造成的锯齿；6px 收边态仍保留独立命中区域
- **数值缓动动效**：刷新后百分比数字与进度条 30fps 指数趋近新值（ease-out 观感），收敛即停，平时零开销
- **正弦调光闪烁**：阶段切换提示由开关式闪烁改为 6 秒 3 次正弦淡入淡出
- **左右贴边自动隐藏**：卡片左/右缘进入所在屏对应竖边 24px 内（两边都够到取更近者）松手，空闲 1.2 秒滑入该侧屏缘，露出 6px **竖向番茄进度条**（水位式：满格齐顶、随剩余时间自上而下回落，落空即到点；剩余 >50% 绿 / 20–50% 黄 / <20% 红）；鼠标触及该侧屏缘即滑出（启动后 5 秒宽限期不隐藏；拖离屏缘后不启用）。左/右停靠全对称：细边热区、region 裁剪、所在屏判定锚点、hover 面板展开方向（左停靠向右展开）随停靠侧镜像，跨屏拖动到哪块屏就贴哪块屏，停靠侧与位置记忆在 `ui_state.json`（旧文件无 `side` 字段按右停靠兼容）
- **hover 详情面板**：悬停单个图标 0.3 秒，在其靠屏内一侧展开 168×64 的局部详情卡片；切换图标只更新对应项，离开轨道和卡片 0.3 秒后收起

**Codex 用量源（v1.28）**
- 数据来自 Codex CLI 所配中转站（`~/.codex/config.toml` 顶层 `model_provider` 指向供应商的 `base_url`，白名单 `uapi.ccwu.cc`；key 为 `~/.codex/auth.json` 的 `OPENAI_API_KEY`，Bearer 鉴权），请求 `GET {base}/v1/usage`
- 额度为 USD 计价订阅，无 5h 窗口：环语义取**周预算剩余比例**（如 (300-17.4)/300），hover 详情给「周 $17.4/$300 · 6天9h 后预计重置 · 今日 $17.4」；`daily_limit_usd=0` 且 `mode=unrestricted` 表示无日限额，今日已用只以文字呈现、绝不折算成比例
- 周重置时刻由 `weekly_window_start + 7 天` 推算（服务端无显式 reset 字段），窗口起点在未来或已越过推算点时显示「等待窗口」而非编造倒计时；安全策略沿用 GLM 源（https + 域名白名单 + DNS 后私网阻断 + 禁重定向 + 响应体 64KB 上限）

**MiMo 用量源（v1.35 槽位 · v1.36 空态语义 · v1.37 本机账本 · v1.39 官方基线）**
- MiMo 是 **token 套餐计量**，不是 GLM / Kimi 那种 5h 窗口百分比，而且**没有开箱即读的官方额度接口**（实测）：Token Plan 网关 `token-plan-cn.xiaomimimo.com/v1`（`tp-` key）只有 `/v1/models` 通，`/usage` `/quota` `/subscription` `/dashboard/billing` 等 130+ 候选路径全 404，对话响应头也不带限流头；账号级官方接口 `mimo-server-cn.xiaomimimo.com/api/user/usage` 与 `/api/user/xiaomi/subscription/self` 存在（返回 `{code:0,data:{percent,resetDate}}`），但只认小米账号会话 cookie——那份库在 MiMo Desktop 运行期间被独占锁死，Chrome 里也没有 xiaomimimo 的 cookie；`platform.xiaomimimo.com/api/v1/*` 是网关统一 401（连 `/api/v1/zzzz` 都 401），枚举不出真路径
- 因此走**本机账本 + 官方基线**：账本是 `~/.local/share/mimocode/mimocode.db`（路径遵循 `MIMOCODE_HOME` / `XDG_DATA_HOME`），只读打开（`mode=ro&immutable=1`）统计 assistant 消息的消耗。**口径 = `input + output + reasoning + cache.read + cache.write`（含缓存读，即引擎的 `total`）**——对过账：官网显示 664,754,691 已用时，本机同口径约 109.5M，而扣掉 `cache.read` 的旧口径只有 4.2M，量纲差 150 倍，缓存读必须算进来。provider 只取 MiMo 自家（`mimo-desktop` 走桌面代理、`xiaomi*` 走 Token Plan / 计费网关），别的供应商不算进来
- **官方基线**（v1.39）：官方已用量只在账号侧，查不到就由使用者从官网「套餐使用情况」抄一次：

  ```json
  "mimo": {
    "budget": 11000000000,
    "baseline_used": 664754691,
    "baseline_local": 109543046,
    "baseline_at": 1791861505,
    "url": "https://…/usage",
    "token": "…",
    "auth": "bearer",
    "header": "Authorization"
  }
  ```

  **最终已用 = `baseline_used` + (本机装机以来 − `baseline_local`)**——起点是官网真值、增量是本机真值，每个数都有出处。`baseline_local` / `baseline_at` 是抄数那一刻本机账本的值与时刻（自动记录，手工改基线时一起填）。配了基线就改用「装机以来全部本机消耗」而非自然月窗口：官网套餐是「11-12 到期」那种 13 号对 12 号的滚动周期，按自然月切会让基线在月初失效
- **已知边界**：基线之后**别的设备**（网页 / 手机 / 其他电脑）的消耗记不进来，环会偏乐观；官网数字更新（续费、换套餐、跨周期）时把新数字告诉我重设基线即可。没配 `budget` 就保持虚线空环，但 hover 与 tooltip 仍如实显示已用量——宁可不画比例，也不拿猜的分母算百分比
- `url` 是**可选**的远端端点，配了就优先于本机账本；`auth` 三选一：`bearer`（默认，`Authorization: Bearer <token>`）/ `header`（`header` 指定的头放原文，如 `X-Api-Key`）/ `cookie`（原文整段作为 `Cookie` 头）。远端响应按字段名做 ≤4 层浅查找：`remaining*` 当剩余、`percent` / `usedRatio` / `used*` 当已用（`100 − 已用`），数值 ≤1 按比例 ×100、>1 按百分数，字符串 `"41%"` 也能吃；重置点取 `reset*` / `nextResetTime` / `expire*`，兼容 epoch 秒、毫秒与 ISO-8601
- 远端安全策略沿用 GLM / Codex 源：仅 https、DNS 解析后逐 IP 阻断私网/环回/链路本地/保留/组播地址、禁重定向（`_OPENER`）、响应体 64KB 上限、10s 超时、429 指数退避；因端点由使用者配置，不做硬编码域名白名单（白名单会让改配置立即失效）
- **两种来源都拿不到数**才返回 None（虚线空环 + `--`）。**没配远端端点**时槽位一直挂着（图标常在）；**配了远端端点却拉不到**才计入无响应，连续 3 轮后整个槽位自动摘牌、配通一次即挂回

**番茄工作闹钟（下段）**
- 锚定作息表：工作日 9:00–11:30、13:30–18:00 两个时段内连续跑「45 分钟工作 ↔ 15 分钟休息」；时段尾自然截断（上午 11:00–11:30、下午 17:30–18:00 为 30 分钟收尾工作段，倒计时递减到 0 正好落在午休/下班边界）
- 节假日 / 调休自适应：chinese-calendar 判定中国法定节假日与周末补班，调休补班的周末照常计时，假期显示「假日」不计时；库缺失或数据超范围时退回「周一~周五」近似
- 状态由墙钟每秒推导（非累计计时）：任意时刻启动即对位、睡眠/挂起后自动恢复、阶段边界不随运行时长漂移
- 时段外显示「待机 / 午休 / 下班 / 假日」+ 下次开工时刻；阶段切换、上/下午开工、午休、下班均弹 Windows 通知并闪烁提示
- 阶段圆点（工作=专注紫 / 休息=teal / 非工作=灰）+ 粗体阶段词（思源黑体）+ 等宽倒计时（冒号每秒呼吸）+ 5px 胶囊进度条（按标准 45/15 分钟归一，与倒计时严格同比例递减，归零即切阶段）

**通用**
- 右键菜单：立即刷新 / 保持展开 / 重置时间显示时刻 / 开机自启 / 退出
- 单击槽位：只刷新对应源；点击展开的详情卡：钉住 / 解除
- 可拖拽移动位置（拽着隐藏态细边拖动，松手处就地恢复整卡；松手时就近更新停靠侧）
- 圆角半透明悬浮窗口
- 支持开机自启动（登录后启动）

## 实施方案

- **语言**: Python 3
- **GUI**: tkinter（无边框置顶窗口 + Win32 分层窗口实现逐像素透明）
- **图像**: Pillow（PIL）绘制电池图标与番茄图标，支持圆角和抗锯齿
- **番茄钟**: `root.after` 每秒驱动倒计时状态机
- **通知**: winotify（WinRT toast）+ 注册表注册应用 AUMID，显示番茄图标与应用名
- **API**: 优先实时读取 ZCode 配置（`~/.zcode/cli/config.json` 当前供应商 + `~/.zcode/v2/config.json` 的 apiKey/baseURL），调用 GLM 配额接口获取用量；详见下方「API 配置来源」
- **刷新**: 后台线程请求 API，主线程更新 UI，5 分钟轮询

## 安装与运行

```bash
pip install -r requirements.txt
python main.py             # 或双击 start.bat（pythonw 无窗口启动）
```

**API 配置来源（优先级从高到低）**：

> **GLM 源当前停用（v1.40）**：`main.py` 的 `DISABLED_SOURCES = ("glm",)` 会一并跳过状态轨槽位、周期刷新与闲忙通知，所以下面这套 GLM 配置优先级暂时用不上（也就不必再为它修 key）。要恢复：删掉该元组里的 `"glm"`；若 key 已失效，先按下方「刷新兜底 key」重跑 `setup_config.py`。

1. **ZCode 当前配置（默认生效，自动跟随更新）**：`~/.zcode/cli/config.json` 的 `model.providerId` 记录 ZCode 当前选中的供应商，其 `apiKey` / `baseURL` 明文存于 `~/.zcode/v2/config.json` 的 `provider[<id>].options`。仪表盘每次刷新（5 分钟）都现读这两个文件，**在 ZCode 里换 key、换供应商后无需任何手动操作**，最迟一个刷新周期自动生效。若活动供应商无可用 key（如切换到 OAuth 类套餐），自动改用配置中任一已启用且带 key 的供应商。
2. **项目 `config.json`**（已被 `.gitignore` 忽略，不会上传 key）：ZCode 不可用时的独立兜底，由 `setup_config.py` 固化。
3. **环境变量** `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN`。
4. **`~/.claude/settings.json`** 的 `env` 字段（兼容 Claude Code）。

> **刷新兜底 key**：兜底 `config.json` 里的 key 过期后，重跑 `python setup_config.py` 即可——它会跳过已有 `config.json`，从 ZCode / 环境变量 / `~/.claude/settings.json` 读取最新配置写入（只覆盖 `base_url` / `token`，`mimo` 等手工段原样保留）。

> **MiMo 用量**：走本机账本 + 官方基线（`config.json` 的 `mimo.budget` / `baseline_used` / `baseline_local` / `baseline_at`，见上方「MiMo 用量源」），零配置也有「本机本月已用」。官网数字变了把新值告诉我重设基线即可；另可选 `url`/`token` 指到远端额度端点。最迟一个刷新周期生效。

**开机自启**：悬浮窗上右键 →「开机自启（点击切换）」，开启后登录 Windows 自动后台启动；对应注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `GlmDashboard`。

**从 Agent / 沙盒环境重启（重要）**：DSH 等自动化沙盒把每条命令放进带 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 的 Windows Job Object，命令一结束整棵进程树（含 `wscript` 拉起的 pythonw）会被强制回收——表现为"启动成功、几秒后无声消失、无任何日志"。正确做法是让 explorer 代为启动，使 pythonw 挂到 explorer 进程树下、脱离沙盒 Job：

```powershell
C:\Windows\explorer.exe "E:\GIT_Space\glm-plan-dashboard\launch-dashboard.vbs"
```

在沙盒里直接 `wscript launch-dashboard.vbs`、`pythonw main.py` 或 `schtasks` 均不可行（前两者被 Job 连坐回收，后者被沙盒拦截）。进程在跑但看不到悬浮窗时，先检查它是否缩成了屏缘 6px 细条（鼠标触及该侧屏缘即滑出），位置记忆在 `ui_state.json`。
